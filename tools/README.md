# מציאת לידים אמיתיים ללא אתר (רואי חשבון / עורכי דין)

הכלי `find-leads.js` שולף מ-Google Maps את כל רואי החשבון ועורכי הדין בערים המרכזיות
בישראל, ומסנן אוטומטית רק את אלה **שאין להם אתר** רשום בפרופיל העסקי בגוגל — כלומר
לידים אמיתיים ומאומתים (שם, כתובת, טלפון, דירוג — הכל ישירות מגוגל, לא ניחוש).

> **חשוב:** גוגל לא חושפת כתובות אימייל דרך ה-API (מעולם לא אספה אותן). את המייל
> תצטרך להשיג בשיחת טלפון קצרה או מהעמוד העסקי בפייסבוק/פנקס אם קיים — העמודה
> `אימייל` בקובץ המוצא נשארת ריקה בכוונה כדי לא למלא אותה בניחוש.

## שלב 1: יצירת מפתח Google Places API

1. היכנס ל-https://console.cloud.google.com/ עם חשבון Google.
2. צור פרויקט חדש (למשל `weblly-leads`).
3. בתפריט **APIs & Services → Library**, חפש **"Places API (New)"** ולחץ **Enable**.
4. בתפריט **APIs & Services → Credentials**, לחץ **Create Credentials → API key**.
5. מומלץ מאוד להגביל את המפתח (**Restrict key**): תחת *API restrictions* בחר רק
   *Places API (New)*. כך גם אם המפתח ידלוף, אי אפשר יהיה להשתמש בו לשירותים אחרים.
6. תצטרך לחבר כרטיס אשראי לחיוב (Billing) — זו דרישה של גוגל גם לשימוש חינמי.
   גוגל נותנת **200$ קרדיט חינמי בכל חודש**; החיפוש המלא בכל הארץ (~100 בקשות)
   עולה בערך 3-5$, כך שבפועל לא תחויב.
7. העתק את המפתח שנוצר (מחרוזת ארוכה שמתחילה ב-`AIza...`).

## שלב 2: הרצת הכלי

```bash
cd tools
GOOGLE_PLACES_API_KEY="AIza...המפתח שלך" node find-leads.js > leads.csv
```

אפשרויות נוספות:

```bash
# רק רואי חשבון, עד 50 לידים
GOOGLE_PLACES_API_KEY=... node find-leads.js --categories="רואה חשבון" --limit=50 > leads.csv

# להוסיף קטגוריות נוספות
GOOGLE_PLACES_API_KEY=... node find-leads.js --categories="רואה חשבון,עורך דין,יועץ מס" > leads.csv
```

הריצה לוקחת כמה דקות (יש השהיה מכוונת בין עמודי תוצאות, כנדרש ע"י גוגל).
בסיום תקבל `leads.csv` עם עמודות: שם העסק, קטגוריה, עיר, כתובת, טלפון, אימייל (ריק),
דירוג, מספר ביקורות, ציון פוטנציאל (מיון לפי דירוג × ותק ביקורות), קישור ל-Google Maps,
ופתיח מכירה מותאם אישית לכל עסק.

פתח את הקובץ באקסל/Google Sheets (תמיכה מלאה בעברית ב-UTF-8).

## למה זו הדרך הנכונה (ולא רשימה "מהזיכרון")

מודל שפה לא יכול לדעת בוודאות אילו עסקים אמיתיים קיימים היום, אילו מהם באמת חסרי
אתר, ומה מספר הטלפון והמייל הנכונים שלהם — כל ניסיון "לנחש" רשימה כזו יחזיר שילוב
של עסקים אמיתיים עם פרטי קשר שגויים ועסקים שלא קיימים בכלל. הכלי הזה שולף נתונים
חיים ומאומתים ישירות ממאגר גוגל, כך שכל שורה בקובץ היא עסק אמיתי עם טלפון וכתובת
נכונים נכון לרגע החיפוש.
